# Site.on — portfólio de Gustavo Dias

Portfólio responsivo, feito em um único arquivo HTML com CSS e JavaScript embutidos. Publicado no GitHub Pages.

## Conteúdo

- Apresentação dos serviços e contato direto pelo WhatsApp.
- Projetos agrupados em seis nichos: saúde animal, beleza, moda, alimentação, fitness e comércio.
- Capturas dos sites, filtros por nicho, efeitos 3D leves nos cards e navegação responsiva.
- Processo em três etapas e apresentação do Gustavo.

Os status distinguem sites publicados de propostas demonstrativas e conceitos de marca. A presença de um site público, por si só, não confirma relação comercial com um cliente.

## Publicação

O arquivo principal é `index.html`; as imagens usadas ficam em `img/`. O repositório está configurado para GitHub Pages na branch `main`.
