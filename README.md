# Site.on por Gustavo Dias

Portfólio responsivo para apresentar projetos reais da Site.on e facilitar o contato de pequenos negócios pelo WhatsApp.

## Conteúdo
- `index.html`: página principal com projetos, benefícios, serviços, processo, apresentação, FAQ e CTAs.
- `projetos/`: uma página de detalhes para cada um dos cinco projetos existentes.
- `css/style.css`: identidade visual premium, responsiva e com preferência por movimento reduzido respeitada.
- `js/main.js`: menu móvel acessível e ano automático no rodapé.
- `img/` e `fonts/`: capturas, imagens, logotipo e fonte licenciada reaproveitados do repositório original.

## Publicação
O site é estático e pode ser publicado pelo GitHub Pages a partir da branch `main` e da raiz do repositório.
